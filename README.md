# RAR Inbox AI Assist

**Architecture v0.2 · 27 October 2026 · NOT production software**

Human-reviewed AI reply assistant for **Nabiad Distribution Limited**, designed for Messenger chats opened in Meta Business Suite on desktop Chrome. Planned workflow: **three grounded AI suggestions** (Professional, Friendly, Short; optional fourth Sales-focused) → Select → Edit → Insert/Copy → **staff manually sends**. Never automatic Send.

> **Project status:** This repository contains architecture documents, planning and AI coding-agent guidance. A functioning Chrome extension, WordPress plugin, Meta integration and tested production release have **not** been implemented. Do not treat the ZIP as an installable application.

## Planned features

- 3–4 context-aware Bangla, Banglish and English reply options generated by OpenAI or Claude through a secure server-side API, with independent guardrails and source chips.
- Approved Nabiad FAQs, dealer pricing (linked verified dealer only), stock buckets, business rules and human escalation.
- User-controlled selection and edit; safe Insert only into exactly matched Meta thread when platform permission/adapter permit, otherwise Copy-only with user-selected/pasted input.
- Personal-data masking, no persistent raw chat or unmasked AI reply, server-held API keys, revocable staff tokens, rate/budget caps.
- Separate hosting feasibility gate protecting nabiad.com under marketing-campaign traffic.
