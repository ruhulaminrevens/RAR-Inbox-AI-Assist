# Contributing

This is an architecture-first repository. Read [CLAUDE.md](CLAUDE.md), [agent rules](.cursorrules), [decisions](docs/DECISIONS.md) and the [Plan](docs/06_Plan.md). Before application code, record AUTH/G0/G1 scope and evidence. Reference requirement/task IDs on PRs; update related documents and attach executed test results. Never commit API keys, customer chat transcripts, unmasked personal data, tokens or confidential dealer price lists.
